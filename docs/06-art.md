# 06 · 美术风格说明

## 总基调

**Rusty Lake 平涂插画 × Dreamcore × Y2K 千禧校园怪谈**。
一句话：用儿童绘本的笔触画不安的东西，用 CRT 的噪声盖温柔的心。

## 风格三层

1. **基底层（Rusty Lake 式平涂）**
   - 矢量感平涂 + 硬边阴影，无渐变或仅双色渐变；轮廓线极细或无。
   - 人物：兽首人身，身体瘦长、姿态僵直；人类角色（林晚）眼睛小而平静。
   - 透视：一点透视的"舞台布景"构图，正面墙、左右微斜——降低绘制难度且最像 Rusty Lake。

2. **时代滤镜层（区分三个世界，纯 shader/overlay 实现，零额外美术）**
   | 世界 | 滤镜 |
   |---|---|
   | 2026 现实 | 轻胶片颗粒 + 暗角 |
   | 2001 过去 | 降饱和偏褐 + VHS 扫描线 + 色度溢出（chroma bleed） |
   | 梦境/档案库 | 加重颗粒 + 缓慢呼吸式暗角 + 偶发单帧故障（glitch） |

3. **Y2K 符号层（道具语言）**
   CRT 显示器、Win98 窗口、软盘、VHS、磁带、搪瓷缸、绿罩台灯、铁皮档案柜、蜡封、毛玻璃、绿色黑板、老式日光灯管（频闪）。

## 调色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 主底色 | `#1C1A17` | 近黑的暖褐（夜） |
| 纸/米黄 | `#E8DCC0` | 档案、灯光、信纸 |
| 档案绿 | `#3E5C4B` | 档案柜、黑板、制服 |
| 锈红 | `#8C3B2E` | 印章、危险、狐狸 |
| CRT青 | `#7FD4C1` | 屏幕光、梦境高光 |
| 2001褐 | `#A98E6F` | 过去时间线主调 |

规则：每个镜头最多 5 个主色；惊悚场景靠减色（趋近双色）而非加红。

## 角色设计要点

- **林晚**：深色齐肩发、灰绿色风衣、帆布包；剪影必须一眼可辨（玩家唯一的"人脸"）。
- **未来们**：同一剪影换发型与衣着：26岁马尾+格子衫、30岁短发+大衣、35岁盘发+针织衫、50岁银发+围巾——靠剪影讲年龄。
- **六兽**：统一身体模板（西装/长衫差分），只换头与一件标志道具——6 个角色≈1.5 个角色的工作量。
- **周韵秋**：2001版与林晚共用体型模板换头发；2026版导师只闻其声+背影（节省+悬念）。

## 资产清单与预算（独立开发者可控）

| 类别 | 数量 | 说明 |
|---|---|---|
| 场景背景 | 28 张 | 2048×1536，平涂，每张 0.5–1 天 |
| 角色立绘 | 10 个（共用模板） | 每个 2–3 姿态差分 |
| 物品图标 | ~60 个 | 256×256，每个15–30分钟 |
| UI 套件 | 1 套 | 物品栏/按钮/卷宗界面/Win98组件 |
| 特效 | shader 为主 | 颗粒/VHS/暗角/glitch 各一个可复用 pipeline |

工具建议：Affinity Designer / Figma 画平涂矢量导出 PNG；不会画画时可先用灰盒色块+文字占位完成全部逻辑，再统一替换（见 09-mvp）。
