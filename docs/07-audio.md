# 07 · 音效方案

## 设计原则

- Rusty Lake 式：**安静为主，声音即线索**。无配音，全字幕。
- 三层结构：环境底噪（loop）→ 主题旋律（稀疏出现）→ 交互音效（短促）。
- 心理惊悚靠"声音的不对劲"（钟摆漏拍、广播半句、磁带音高漂移），不靠音量惊吓。

## 音乐（6–8 段即可，单段 60–90 秒 loop）

| 曲目 | 用途 | 配器/气质 |
|---|---|---|
| 主题曲《归档》 | 标题/结局 | 钢琴单音+磁带饱和，温暖微噪 |
| 现实日常 | 第1章白天 | 钢琴+环境采样，平静微倦 |
| 夜图书馆 | 第2章 | 低音提琴拨弦+翻页采样节奏 |
| 记忆 | 第3章 | 八音盒+磁带抖动（wow/flutter） |
| 档案库 | 第4-5章梦境 | 暗色 pad+打字机/盖章声采样节拍 |
| 狐狸动机 | 狐狸出场 | 走音的圆舞曲三拍，仅4小节 |
| 答辩 | 第6章 | 主题曲变奏，弦乐渐入 |
| 隐藏结局 | B∞ | 主题曲+2001版"老磁带录音"双轨叠放（25年同一旋律） |

**动机设计**：六兽各配一个 2 秒声音签名（乌鸦=钢笔划纸、鹿=钟摆、狐狸=三拍走音、猫头鹰=翻页、白兔=怀表滴答、鲤鱼=水滴入静湖）。动机先于角色出现=预告与暗示。

## 环境底噪（每场景 1 个 loop，30–60 秒）

日光灯管嗡鸣 / 老建筑木地板呼吸 / 空调外机远鸣 / 夏夜虫鸣（2001羊山）/ 档案库的纸张窸窣 / 湖水极轻的拍岸 / CRT 高频啸叫（15.7kHz 微量，机房）/ VHS 走带声。

## 交互音效（~40 个）

分类：点击通用、物品获得（盖章）、抽屉/柜门木与铁两套、转盘锁咔哒、密码正确（厚重弹簧）、密码错误（闷响）、翻档案纸、羽毛笔书写、印章碎裂、电梯（老式铃+钢缆）、玻璃裂、水声组、glitch 故障组。

## 心理惊悚专用声音事件

- 椅子集体转向：只有一声极轻的木材摩擦（看到之后才反应过来）。
- 录像带对视帧：所有环境音瞬间消失 1.5 秒（静默比巨响可怕）。
- 循环走廊：每圈底噪音高降低半音（潜意识不安）。
- 404 时刻：机房所有 CRT 同时换成同一频率嗡鸣。
- **温暖原则**：结局章节所有"不对劲声音"逐一恢复正常（钟摆补上漏拍）——用声音完成治愈闭环。

## 实现与资源

- Phaser 内置 WebAudio（`this.sound`），无需额外库；音乐 crossfade 用两个并行实例做音量插值。
- 格式：`.m4a`（iOS 友好）+ `.ogg` 兜底；底噪 mono 节省体积；总音频预算 ≤ 25 MB。
- 免费资源：freesound.org（CC0 优先）、日本 OtoLogic、自己用手机录（关抽屉、翻书、盖章是最容易自录的）；音乐可用 LMMS/GarageBand 完成上述简单配器。
