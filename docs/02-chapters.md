# 02 · 章节设计

> 6 章 + 真结局 + 隐藏结局。每章 12–20 分钟，总流程 90–120 分钟。
> 每章结构：现实场景 → 异变触发 → 梦境场景 → 章末叙事揭示 → 残缺档案（隐藏收集）。

---

## 第一章 · 失踪的档案（约15分钟，谜题1-1～1-4）

**场景**：历史学院楼（办公室、走廊）→ 档案馆怀安楼（查档大厅、库房、资料室）
**时间**：2026年6月，午后到傍晚。

**流程**：
1. 开场：答辩倒计时14天。林晚在历史学院走廊，导师周韵秋办公室门上贴着便条："去档案馆帮我调 NJU-2001-404，钥匙密码你猜得到。"（谜题1-1，教学关）
2. 办公室内拿到借阅证和一摞旧借阅单，整理后发现2001年曾有人借阅同一卷宗，借阅人栏空白，夹着一根乌鸦羽毛（谜题1-2）。
3. 档案馆查档：按档号规则定位档案柜——柜中空空，只有一盘VHS，标签"2001.6.21"（谜题1-3）。
4. 资料室老电视+录像机，调谐噪声后看到2001年鼓楼老图书馆的画面：年轻女子在归档，镜头尽头乌鸦头人转头直视镜头。定格帧上有索书号 K295.3/2001（谜题1-4）。
5. **章末钩子**：闭馆广播响起，林晚回头，查档大厅所有椅子都朝向她摆好了。黑屏，章节卡。

**心理惊悚手法**：被注视感（椅子、录像里的对视）、广播失真。无 jump scare。
**残缺档案①**：借阅单堆里多出一张1987年的，背面有烧痕——可收入物品栏。
**玩家此章获得**：世界观钩子（25年前有人查过同一档案）、索书号线索、乌鸦初登场。

## 第二章 · 第七档案库（约18分钟，谜题2-1～2-4）

**场景**：杜厦图书馆（大厅、五层C区）→ 无限图书馆（梦境）→ 怀安楼电梯 → 第七档案库B7
**时间**：当晚，闭馆前到午夜。

**流程**：
1. OPAC旧电脑（Win98界面）检索索书号，馆藏位置"五层C区"。书架上该书缺失，留下一个书的"剪影"。
2. 重排七本错架书，书名首字连成"嫏嬛在水之南"（谜题2-2）。此刻熄灯——**五层C区开始闭环**：无论往哪走都回到同一排书架，窗外的月亮每圈大一号。
3. 猫头鹰馆员出现，考校三道校史题（答案都能在本层找到），通过后授予刻着"七"的黄铜钥匙（谜题2-3）。
4. 走出图书馆，夜路沿湖到嫏嬛路怀安楼。电梯面板只有1–5和B1，破解羽毛上的按键序列后，面板裂开露出 **B7**（谜题2-4）。
5. B7：无尽的绿色档案柜阵列，乌鸦先生在登记台后写字，头也不抬："姓名？……林晚。你的柜子还是空的。"他讲解规则（每柜一种未来/档案须本人签署/404即尚未发生——此条他说到一半被狐狸的笑声打断）。
6. **章末**：最近的档案柜虚掩着。拉开——26岁的林晚坐在柜子里的台灯下改论文，抬头："你来得比我想象的晚。"

**残缺档案②**：猫头鹰答题全对（不答错一次）额外奖励。
**玩家此章获得**：第七档案库规则、26岁未来登场、狐狸的存在感（只闻笑声）。

## 第三章 · 白兔时间线（约18分钟，谜题3-1～3-4）

**场景**：宿舍（现实）→ 循环走廊（梦境）→ 2001羊山工地（回溯）→ 校史馆前广场（2026）
**时间**：当夜，林晚回宿舍后入梦。

**流程**：
1. 宿舍场景：洗漱、关灯，镜中一闪而过的白色耳朵。躺下后惊醒——走廊变成无限循环（谜题3-1，每圈一个细节变化，跟随白兔怀表声辨向）。
2. 走廊尽头是一扇不属于宿舍楼的木门：推开是**2001年的羊山工地**——仙林校区还是田野，三棵幼小的水杉，远处放着工地广播。组合工具挖出时间胶囊（谜题3-2）。
3. 胶囊内：周韵秋的信（开头被水渍模糊）、半张合影、一本上锁的日记。转轮锁密码=她做出选择的日子：2001年夏至6月21日（谜题3-3）。
4. 日记揭示：2001年周韵秋在鼓楼老图书馆地下也找到过"第七档案库的前身"，也见过自己的未来们。日记最后一页："我决定留下来。不是因为这是正确答案，而是因为我愿意为它负责。"
5. 白兔给出6片记忆碎片，在时间线轨道上拼接；其中两片是黑白的（周韵秋的），必须插进林晚的彩色记忆之间才能完成——**她们的人生节点完全重合**（谜题3-4）。
6. **章末**：拼接完成的瞬间，墙上的CRT电视自动亮起，雪花中接通一个越洋视频：30岁的林晚在海外档案馆，身后是凌晨四点的窗。"别用我来吓自己。我过得很好——也很想家。这两件事不矛盾。"

**残缺档案③**：循环走廊里某一圈，门缝下塞着一份。
**玩家此章获得**：周韵秋=前一个"她"、记忆与时间的关系、30岁未来登场。

## 第四章 · 乌鸦记录室（约18分钟，谜题4-1～4-4）

**场景**：校史博物馆（现实，清晨）→ 乌鸦记录室（梦境）→ 鹿的时钟走廊 → 镜像档案室
**时间**：次日。现实与梦境的边界开始失效（白天也能进入）。

**流程**：
1. 校史博物馆三层，"校史长卷"展柜玻璃上倒映出不存在的第四层楼梯。上楼即乌鸦记录室：上千支自动书写的羽毛笔，每支笔记录一个人的一生。
2. 林晚找到自己三个未来的档案——全被篡改：好的句子被涂黑，每一页页脚有狐狸爪印水印（谜题4-1：对照乌鸦的镜文底稿找出并恢复每份3处谎言）。
3. 鹿女士出现："要看见被涂掉的东西，你得先把时间摆正。"时钟走廊：四扇门（1919北大楼/2001羊山/2009开馆/2026现在），用鹿角时针按年代顺序指认信物开门，每扇门后是一段无对白的vignette（谜题4-2）。
4. 镜像档案室：房间与镜中房间联动但左右颠倒，操作需反向推理，取回最后一份原始底稿（谜题4-3）。
5. 狐狸正面登场，设"正确答案保险柜"赌局："转出完美人生的年份，我就把你的未来还给你。"任何年份都错；转出"无解"二字柜门弹开——里面只有一张狐狸面具（谜题4-4）。狐狸鞠躬退场："你猜对了我是什么。但你还没猜对你自己是什么。"
6. **章末**：35岁的林晚在记录室门口等她——中学历史老师，手里捏着半截粉笔。"我没有失败。我只是……换了一间教室。"

**残缺档案④**：镜像档案室中只能在镜中世界拿到。
**玩家此章获得**：狐狸的手法（把每条路涂改成失败）、35岁未来登场、"无解即解"的主题预演。

## 第五章 · 档案404（约18分钟，谜题5-1～5-4）

**场景**：旧电脑机房（现实+Win98界面）→ 校园湖 → 镜湖（梦境）→ 2001鼓楼老图书馆（双屏联动）
**时间**：当晚。本章是惊悚浓度峰值，也是反转点。

**流程**：
1. 机房：CRT显示器阵列，只有一台亮着。登录档案系统查"林晚"——**HTTP 404：未找到该人生**。利用便签与CRT烧屏残影破解管理员密码进入删除日志（谜题5-1）：档案404删除于2001-06-21，操作者签名"林晚"。
2. 狐狸的声音从所有CRT同时响起："看，连未来的你都放弃了你。"机房所有屏幕亮起雪花。林晚逃出机房，来到校园湖边。
3. 湖心一盏纸灯。折纸船：信纸+蜡封+羽毛笔写下名字（谜题5-2）。鲤鱼浮出，拖船入湖——**湖的倒影是2001年的鼓楼校园**，船穿过水面即穿过25年。
4. 双屏联动（谜题5-3）：上屏2001鼓楼老图书馆（操纵年轻的周韵秋），下屏2026第七档案库（操纵林晚），两个时空共用一个"还书箱"传递物品，互相解锁。完成后取得档案404的另一半。
5. 真相：删除日志上的"林晚"签名是狐狸伪造的爪印变体；档案404根本不是被删除——**是周韵秋2001年故意留白的**。她的信："这卷档案我留白了。因为未来不该被提前写好。404不是丢失，是尚未发生。把它交给下一个找到这里的人。"
6. 重组档案404（谜题5-4）：两半档案+林晚的证件照+空白纸 → 生成一卷新档案，封面：**林晚-2026-？**
7. **章末**：乌鸦先生收起所有羽毛笔，第一次抬头看她："明天答辩。委员会已经到齐了。"

**残缺档案⑤**：2001侧书架深处，只有双屏联动时够得到。
**玩家此章获得**：全部真相、与周韵秋跨时空相遇、属于自己的空白档案。

## 第六章 · 毕业答辩（约15分钟，谜题6-1～6-3）

**场景**：敬文学生活动中心 → 恩玲剧场（梦境版：观众席无限延伸进黑暗，台上只有一桌一椅一台幻灯机）

**流程**：
1. 答辩委员就座：乌鸦（记录）、鹿（时间）、猫头鹰（知识）、白兔（记忆）、鲤鱼（命运）。狐狸的座位空着——桌上只摆着那张面具。
2. 答辩第一环节：整理幻灯片（谜题6-1）——她的论文就是这场游戏里收集的全部校史，按年代排列即过（剧情回顾机制）。
3. 第二环节：三个未来从观众席起立提问，每人各有一句诛心之问。回答方式不是选项，而是**归还遗失之物**（谜题6-2）：台灯→26岁（坚持也需要被照亮），半张合影→30岁（远行的人需要牵挂），粉笔→35岁（平凡是一种传承）。她们微笑落座，成为委员。
4. 最终环节：空白档案摊开。章盘四枚章（优/良/正确/错误）逐一尝试、逐一失效——印面落纸即碎成灰。唯一有效操作：羽毛笔签名（谜题6-3）。
5. 签名瞬间，剧场灯光转暖，观众席亮起：座无虚席——全是各个年龄的"她"，以及第二排安静微笑的周韵秋。

## 真结局 · 归档（约5分钟）

签名后，乌鸦推来四个档案柜：**读博 / 出国 / 离开 / 留白**。玩家任选其一放入档案——
**无论选哪个，结局相同且温暖**（机制即主题：没有错误选项）。

归档动画 → 切到清晨六点的杜厦图书馆门口，湖面晨雾，林晚走下台阶，手机屏幕亮着一封已写好的邮件（内容不展示），她按下发送，抬头看见日出。

字幕：**"历史不记录正确答案，只记录被勇敢选择过的人生。"**
制作名单背景：六只动物在湖边各自做着自己的事，白兔的怀表停了，它毫不在意。

## 隐藏结局 · 历史学者（约8分钟，需集齐6份残缺档案）

**收集条件**（每章一份，错过可在第六章开场前回收）：
①烧痕借阅单（第1章）②猫头鹰全对奖励（第2章）③循环走廊门缝（第3章）④镜中档案（第4章）⑤2001书架深处（第5章）⑥答辩剧场狐狸空座下（第6章）。
每份档案拾取后需做一次"修复"小交互（拼合碎片/补写缺字/贴回照片，各30秒）。

**触发**：真结局签名后，电梯面板浮现 **B∞**。
**最终谜题 H-1**：最深处的门有六兽门环，将修复档案中得到的六件信物（羽毛/鹿角扣/狐面/鹰羽袖标/怀表/鱼鳞灯）按剧情登场顺序嵌入。

**最深档案室**：一盏台灯，一位50岁的档案管理员抬起头——是林晚自己。
"欢迎。这里保管着每一个你没有成为的你。一个也没有丢。"
她身后的柜子上贴着泛黄的标签，最旧的一张写着：**周韵秋，2001**。
她把台灯递过来——和2001年周韵秋接过的是同一盏。

成就解锁：**历史学者**。
字幕：**"历史学家的工作不是评判过去，而是温柔地保存它。"**
