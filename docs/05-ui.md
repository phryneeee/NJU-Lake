# 05 · UI 方案（iPad 优先）

## 基本规格

- **逻辑分辨率**：2048×1536（4:3，iPad 原生比例），Phaser `Scale.FIT + autoCenter`。
- 横屏锁定；iPhone 兼容时左右加暗化边条（信箱式），不重排版式。
- 所有可点击热区 **≥ 88×88 pt**（手指友好）；热区之间最小间距 24pt。
- 全程**无文字输入**：密码用转盘/键盘面板点击，签名用手指划动轨迹（不校验笔迹）。

## 布局（Rusty Lake 同构）

```
┌──────────────────────────────────────────┐
│ [物品栏：8格，顶部居中横排]      [菜单≡] │
│                                          │
│                                          │
│   ◀            场景画面             ▶   │
│        （固定镜头，点击交互）             │
│                                          │
│              [章节名浮现区]               │
└──────────────────────────────────────────┘
```

- **物品栏**：顶部 8 格。点击物品→选中态（描边发光）→再点场景热区使用；双击物品→放大查看（可旋转/翻面，部分物品背面藏线索）。
- **左右箭头**：镜头切换，半透明，靠屏幕边缘下半区（避开物品栏）。
- **菜单**：暂停/继续、章节选择（已通关章节）、设置（音量、字幕、颗粒效果开关）、存档自动进行（无手动存档，Rusty Lake 惯例）。

## 交互反馈

| 状态 | 反馈 |
|---|---|
| 可交互热区 | 默认不显示提示；设置中可开"轻微微光呼吸"辅助模式 |
| 点击有效 | 短促音效+目标轻微缩放 |
| 点击无效物 | 林晚的一句内心独白（文本气泡，兼作叙事填充） |
| 谜题卡关超5分钟 | 乌鸦飞落在线索物附近（柔性提示系统） |
| 获得物品 | 物品飞入物品栏+登记音效（盖章声） |

## 专用界面（全屏子场景）

1. **Win98 桌面**（2-1、5-1）：像素字体、灰色立体按钮、开始菜单、蓝屏彩蛋。做成可复用的 `RetroOS` UI 组件。
2. **档案阅读界面**：牛皮纸卷宗摊开，左页文字右页照片，翻页交互；所有"档案"类叙事文本统一走此界面。
3. **VHS 播放界面**（1-4）：扫描线+噪声 shader，左右两个旋钮。
4. **双屏联动界面**（5-3）：上下分栏各占 50%，中缝是"还书箱"传送带。
5. **对话**：无配音、无对话框堆叠——单行字幕式文本浮现于画面下方（Rusty Lake 式），角色说话时头部轻微动画。

## 字体与文案

- 正文：思源宋体（简体）；Win98 界面：Zpix/Fusion Pixel 像素字体；档案体：仿宋。
- 文案原则：短句、克制、不解释隐喻。所有谜题提示藏在环境文本里而非 UI 弹窗。

## 无障碍与防卡死

- 设置内提供"谜题跳过"（同一谜题失败 10 次后浮现，跳过不影响真结局、但锁隐藏结局——保护成就价值）。
- 颗粒/闪烁效果可关（光敏友好）。
- 自动存档粒度：每个谜题完成即存（localStorage / Capacitor Preferences）。
