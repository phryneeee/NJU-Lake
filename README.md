# 《第七档案库》（The Seventh Archive）

> Rusty Lake 风格 · 点击式解谜 · 心理惊悚 · 校园怪谈 · 非商业
> 舞台：南京大学仙林校区（2026）× 鼓楼校区/羊山（2001）
> 主题：**"人生不是寻找正确答案，而是接受自己选择的答案。"**

历史学院硕士生林晚在毕业答辩前两周，被导师派去档案馆调阅一卷 2001 年的校史档案。
档案失踪了，借阅单上只有一根乌鸦羽毛——而档案馆所在的那条路，真的叫**嫏嬛路**。

- 单人 · 90–120 分钟 · 6 章 + 真结局《归档》+ 隐藏结局《历史学者》
- 24 个主线谜题 + 6 份残缺档案收集
- Phaser 3 + TypeScript + Capacitor → iPad / TestFlight

## 运行（灰盒开发版）

```bash
npm install
npm run dev        # 浏览器打开提示的地址（iPad 同局域网可直接访问调试）
npm run typecheck  # TS 严格检查
npm run validate   # 数据一致性校验（房间JSON引用的flag/物品/文案/谜题）
npm run build      # 产物在 dist/，可直接作为 Capacitor webDir
```

当前进度：**阶段0–6 完成，灰盒全流程闭环**——第1–6章+真结局《归档》+隐藏结局《历史学者》连续可玩（31房间、22谜题、残缺档案①–⑥）。剩余：美术替换、音频、打磨（错过的残缺档案暂不可回收，待打磨阶段加回收点）。
灰盒模式下热区有描边和 id 标注（`RoomScene.ts` 的 `GREYBOX` 开关）。

## 体量自检（独立开发者 1–2 个月）

- 实绘背景约 28 张（平涂风格，变体复用）
- 角色 10 个共用身体模板，物品图标约 60 个
- 谜题组件高度复用（转盘锁×3 处、排序×3 处、Win98×2 处）
- 总包体 < 80MB，无后端、无账号、纯离线

*本作为基于真实校园的虚构故事，非商业粉丝创作，不使用真实人物。*
